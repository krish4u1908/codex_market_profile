# Source Lineage

## New Divergence V1

The new repository began from the verified R6D branch source at upstream commit
`65ae2c5cb7793ec32a3ae515e3a0aa6365ad2c14`. The recovered source was sealed in
local commit `325c61ff64729e1f3757e0d0bc08d026252b1112` and tagged
`baseline-r6d-offline-gui-65ae2c5` before New Divergence files were added.

New Divergence runtime authority is caller-supplied normalized events or
read-only physical collector JSONL streamed from an explicit tar archive.
Collector startup metadata selects the BankNifty Index and active Futures
symbol. Minute CSV, generated research reports, outcomes, UI payloads, and
fixed-date dictionaries are not inference inputs.

The V1.0.3 nightly context boundary reads only collector
`raw/YYYY-MM-DD/events_*.jsonl` and `oi/YYYY-MM-DD/oi_*.jsonl` files from an
explicit data root. It records every opened file's size, modification time,
SHA-256, parse count, session quality, selected symbols, contracts, and
expiries. SQLite profile bins and immutable context snapshots are derived
outputs; they are not inputs to threshold selection or the frozen intraday
divergence classifier.

The V1.0.11 cash-sample boundary is separate from both inference and nightly
context. It reads only completed
`minute/YYYY-MM-DD/market_1m.csv` cash-constituent rows plus same-session
`metadata/startup_*.json`. It publishes equal-vote breadth and the unweighted
sum of constituent minute share volume under an explicit direct session root.
Source hashes, coverage, and publication clocks are retained in an independent
manifest. These rows are browser data only and cannot enter engine thresholds,
episode state, or the transition ledger.

V1.0.12 consumes the nightly builder's immutable V2 context bundle only in the
calculation-free browser projection. The bundle is derived from completed raw
and OI sessions strictly before the replay date. It contains signed OI-VPOCs
and the canonical BankNifty-reference Futures-volume bins, VPOC, and contiguous
70% VAH/VAL. The projection verifies bundle hashes and identity before use;
these levels have no import path into the divergence engine.

V1.0.13 retains a compact, hashed active-Futures market counter in each new
replay run. Together with the already retained Futures and fixed-strike option
OI receipts, it produces the developing 09:45-to-cursor ID overlays. This
artifact is read only by browser projection; it is not ingested by the
divergence engine. The unchanged nightly context calculation keeps its V1.0.12
producer identity so the verified context cache remains reusable.

## R6C0 raw-provenance boundary

Runtime authority is physical WebSocket and REST JSONL supplied through an
explicit external data root. Verified research packages are source-recovery
and post-generation comparison authorities only, never runtime inputs.
Canonical inventory context is passed as causal in-memory records.

- R1D supplies trusted/quarantined component lineage only; its archived legacy application is excluded.
- R6A supplies verified raw parsing, divergence detection, and descriptive participation primitives.
- Inventory Canonical Revision 2 supplies BankNifty-reference inventory code and semantics.
- R6B2A supplies causal clock and mechanism adjudication documents.
- R6B2R supplies the verified lifecycle/resolution implementation semantics.
- R5 RC1 is retained as historical GUI/reference lineage only; generated GUI and analytical outputs are excluded.

Every imported file is recorded in `manifests/imported_source_inventory.csv`. Excluded categories and representative paths are recorded in `manifests/excluded_source_inventory.csv`.

No port 8803/8804 deployment is source authority.
# R6C0I inventory provenance

The canonical inventory implementation reads only explicitly supplied WebSocket market JSONL and REST OI JSONL roots. It discovers eligible sessions chronologically, maps Futures incremental volume and signed OI receipts backward to the latest causal BankNifty Index receipt, and writes only to an explicit new output directory. `market_1m.csv`, research-package imports, implicit collector roots, and source-relative outputs are prohibited at runtime.
# R6C0T participation lineage

Participation consumes WebSocket and REST JSONL beneath an explicit collector root. Episode anchors are generated by the repository divergence/lifecycle engines during the same run, carry raw run and engine/configuration hashes, and are serialized only inside that run’s output root. Production generation does not read R3/R4/R5 or research-package outputs.
