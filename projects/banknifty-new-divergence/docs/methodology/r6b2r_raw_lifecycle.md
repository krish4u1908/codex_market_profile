# Raw Lifecycle Methodology

Two clean execution paths process physical raw JSONL with the locked R6A parser/detector and Inventory Canonical Revision 2 context. Neither A nor B reads R3, R5, R6B2, R6B2A, outcome, participation, or profitability tables.

Each pass independently builds synchronized basis rows, frozen divergence episodes, dependency groups, standalone Index responses, dense resolution observations, and transition-only lifecycle outputs. The two paths are sealed and byte-compared before Reference C is opened.

The diagnostic dense view records every valid resolution observation. The append-only contract records only effective lifecycle transitions. Episode and snapshot views are generated separately and cannot backdate causal events.
